Control de Ventas

Histórico de ventas diarias para agencias de transporte

Control de Ventas es una aplicación para Mac y Android que lee el reporte diario “Cuadre de caja detallado” en formato HTML y lleva el histórico de ventas de una agencia: tiquetes vendidos, anulaciones, encomiendas y la comisión del administrador, con comparaciones entre años.

Cómo funciona

  • El reporte se lee en el propio dispositivo; no se envía a ningún servidor.
  • Si el usuario conecta su cuenta de Google, la aplicación crea hojas de cálculo en el Google Drive de ese usuario para guardar el histórico y verlo desde varios dispositivos.
  • La aplicación solo puede acceder a los archivos que ella misma crea (permiso drive.file). No ve ningún otro archivo del Drive del usuario.
